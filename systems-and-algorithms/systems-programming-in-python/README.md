# Systems Programming in Python

Simulations and small distributed systems exploring core operating system concepts: virtual memory paging, CPU scheduling, concurrency with threads and semaphores, socket communication, and distributed file storage.

| Project | Concepts |
|---------|----------|
| [Memory Paging Simulator](memory-paging-simulator/) | Virtual memory, page faults, FIFO / Optimal / WSClock replacement |
| [Job Scheduler](job-scheduler/) | Shortest Job First scheduling, producer–consumer, threads, semaphores, UDP sockets |
| [CPU Task Queue](cpu-task-queue/) | Client–server job queue, mutexes, semaphores, UDP sockets |
| [Distributed Storage](distributed-storage/) | Metadata server, storage nodes, file chunking across nodes, SQLite, TCP sockets, JSON messaging |

## Tech

Python · threading · socket / socketserver · SQLite · JSON
